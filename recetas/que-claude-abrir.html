Claude Code vs Desktop vs Cowork vs claude.ai: cuál usar

Claude Code en la terminal, la app de escritorio, Cowork, el chat y Claude Code en la web: qué es cada uno, dónde corre, qué plan pide y cuál abrir.

Probado con Claude Code 2.1.316 · revisado 2026-11-01

Ver los archivos en GitHub Gratis · licencia MIT

Resumen y veredicto

Claude y Claude Code no son lo mismo. Claude es el asistente con el que conversas en claude.ai (web, escritorio y móvil). Claude Code es la herramienta de programación con agentes: lee tu proyecto, edita archivos y ejecuta comandos. La documentación oficial dice que Claude Code usa el mismo motor en todas sus superficies (terminal, extensiones de IDE, app de escritorio, web y móvil) y que tu CLAUDE.md, tu configuración y tus servidores MCP valen en todas las locales. Cowork es otra cosa: lleva las capacidades de agente de Claude Code al trabajo de conocimiento que no es programar, con la misma arquitectura y sin terminal.

Regla rápida para programadores:

  • Trabajas sobre el código de tu PC → Claude Code (terminal, VS Code o pestaña Code de la app).
  • Quieres dejar una tarea larga corriendo aunque cierres el portátil → Claude Code en la web.
  • La tarea es de documentos, investigación u hojas de cálculo → Cowork.
  • Quieres preguntar o pensar en voz alta → el chat.

La tabla, el árbol de decisión y los comandos están también en el repositorio ctrlia-que-claude-abrir.

Cómo lo probamos (metodología)

Esta comparativa es documental: no mide rendimiento, ordena lo que dicen las fuentes oficiales de Anthropic a fecha de 1-nov-2026 (páginas de plataformas, escritorio, web, disponibilidad de funciones, centro de ayuda de Cowork y precios). Cada producto se responde con las mismas cinco preguntas: para qué sirve, dónde se ejecuta el trabajo, qué hay que instalar, en qué sistemas funciona y qué plan lo incluye.

Lo que comprobamos en nuestro PC (Linux, Claude Code 2.1.316, sesión de claude.ai con plan Max): claude auth status muestra el método de acceso y el plan, y claude --help confirma las opciones --desktop y --cloud. No probamos Cowork, la app de escritorio en Windows o macOS, ni una sesión en la nube de punta a punta; /desktop solo funciona en macOS y Windows x64, así que en Linux no se puede probar. Cuando lo hagamos, actualizaremos esta página y su fecha.

Claude Code en la terminal (CLI)

  • Qué es: el programa claude que ejecutas dentro de la carpeta de tu proyecto. Según la página oficial de plataformas es la superficie más completa: el scripting y el Agent SDK solo existen en la CLI, y es la única (junto con las extensiones de VS Code y JetBrains) que funciona también con proveedores de terceros como Amazon Bedrock, Google Cloud o Microsoft Foundry.
  • Dónde corre: en tu máquina, con tus archivos y herramientas.
  • Instalación: curl -fsSL https://claude.ai/install.sh | bash en macOS, Linux y WSL, o los instaladores de PowerShell y CMD en Windows (receta para Windows).
  • Planes: Pro, Max, Ultra, Team o Enterprise, o una clave de API de Claude Console (pago por uso). El plan Free no incluye Claude Code.
  • Para quién: quien vive en la terminal, automatiza con claude -p, usa servidores remotos o quiere todas las funciones. Si prefieres tu editor, la extensión de VS Code o el plugin de JetBrains usan el mismo motor (receta de VS Code).

Para saber con qué cuenta y plan lo estás usando:

claude auth status   # authMethod (claude.ai o API) y subscriptionType
# dentro de una sesión:
/status

App Claude Desktop (pestaña Code) y Cowork

La app de escritorio de Claude reúne el chat, Cowork y Claude Code. Claude Code está en la pestaña Code de la barra lateral e incluye el motor, así que no hace falta instalar Node.js ni la CLI. Lo que añade frente a la terminal:

  • Visor de diferencias para revisar cambios archivo por archivo y comentar líneas.
  • Vista previa de tu app en un panel de navegador.
  • Sesiones en paralelo (cada una puede ir en su worktree de git) y tareas programadas.
  • Dispatch: mandarle tareas desde el móvil (solo Pro, Max y Ultra).
  • Entornos Local, SSH, Cloud o WSL.

Sistemas: macOS (Intel y Apple Silicon), Windows x64 y ARM64, y Linux en beta para Ubuntu y Debian con apt. Requiere suscripción de pago y sesión de claude.ai. En Linux, sigue los pasos oficiales de desktop-linux: el repositorio y la clave de firma se toman de esa página, no de terceros.

Cowork se usa desde la misma app. Según el centro de ayuda, sus tareas se ejecutan en la nube, en servidores de Anthropic en un entorno aislado, y la app tiene que estar abierta cuando necesitan tus archivos locales o el navegador. Cowork está en los planes de pago (Pro, Max, Ultra, Team y Enterprise) y también en web y móvil.

Chat de claude.ai y Claude Code en la web

El chat de claude.ai es lo que tiene el plan Free: conversar en web, escritorio y móvil, buscar en internet, crear archivos y ejecutar código, memoria, conectores y Artifacts. No trabaja sobre tu repositorio ni ejecuta comandos en tu PC.

Claude Code en la web (claude.ai/code) es otra cosa: sesiones de Claude Code que corren en una máquina virtual en la nube gestionada por Anthropic, que siguen funcionando aunque cierres el portátil y que puedes revisar desde cualquier dispositivo, incluida la pestaña Code de la app móvil.

  • Necesitan conectar GitHub: la máquina clona tu repositorio y sube ramas.
  • Están en Pro, Max, Ultra y Team y, en Enterprise, con plazas premium o Chat + Claude Code.
  • Cuentan contra los mismos límites de uso que el resto de Claude, sin cargo aparte por la máquina.
  • No cargan los plugins que instalaste en tu PC, y comandos como /plugin o /resume no funcionan allí.

Desde la terminal puedes pasar trabajo entre superficies:

claude --cloud "Arregla el test inestable de auth.spec.ts"   # nueva sesión en la nube
claude --teleport                                         # traer una sesión de la nube a la terminal
claude --desktop --continue                               # abrir la última sesión en la app de escritorio
# dentro de una sesión de terminal:
/desktop   # continuar esta sesión en la app (macOS y Windows x64)

Cuándo usar cada uno

Pregúntate en este orden:

  1. ¿Vas a cambiar código? Si no: chat (preguntas) o Cowork (documentos, investigación, tareas de varios pasos sin terminal).
  2. ¿El código está en tu PC y necesitas tus herramientas, servidores locales o MCP? Entonces Claude Code local: terminal si quieres todas las funciones y automatizar; pestaña Code de la app si prefieres revisar diffs visualmente y abrir varias sesiones; VS Code o JetBrains si no quieres salir del editor.
  3. ¿La tarea es larga, está en GitHub y quieres apagar el portátil? Claude Code en la web o claude --cloud.
  4. ¿Te vas del escritorio a mitad de una tarea local? Remote Control desde el móvil (guía paso a paso).

Combinaciones que funcionan:

  • Planificar en la terminal con el modo plan y ejecutar en la nube con claude --cloud.
  • Empezar en la terminal y pasar a la app con /desktop para revisar los cambios (requiere suscripción de claude.ai y funciona en macOS y Windows x64).
  • Lanzar en la web desde el móvil y rematar en local con claude --teleport.

Todo comparte el mismo margen de uso del plan, así que más superficies no significa más límite. Si vienes de otra herramienta, mira la comparativa Claude Code vs Codex vs Gemini vs Cursor; si estás empezando, la ruta de Empieza aquí.

Preguntas frecuentes

¿Claude Code y Claude es lo mismo?

No. Claude es el asistente de chat de claude.ai. Claude Code es la herramienta de programación que lee y edita tu proyecto y ejecuta comandos. Comparten cuenta y margen de uso si pagas un plan.

¿Qué diferencia hay entre Claude Code y Cowork?

Cowork usa la misma arquitectura de agente que Claude Code, pero está pensado para trabajo de conocimiento que no es programar y no necesita terminal; sus tareas corren en servidores de Anthropic. Claude Code está enfocado al código de tu repositorio.

¿Puedo usar Claude Code gratis desde la app de escritorio?

No. La pestaña Code pide una suscripción de pago (Pro, Max, Ultra, Team o Enterprise). Con el plan Free solo tienes el chat.

¿Hay app de escritorio para Linux?

Sí, en beta para Ubuntu y Debian, instalada con apt según la página oficial desktop-linux. La CLI funciona en Linux sin beta.

¿Claude Code en la web gasta aparte?

No hay un cargo aparte por la máquina en la nube, pero las sesiones cuentan contra los mismos límites de tu plan, y varias tareas en paralelo consumen más.

Tengo clave de API, ¿qué puedo usar?

La CLI y las extensiones de VS Code y JetBrains. La app de escritorio (salvo Claude Desktop on 3P), la web, el móvil, Remote Control y la extensión de Chrome necesitan una cuenta de claude.ai.
