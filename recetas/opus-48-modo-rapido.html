Claude Code Opus 4.8: el modo rápido acaba el 30-nov, pasa a 5.5

El modo rápido de Opus 4.8 en Claude Code dará error desde el 30-nov-2026. Comprueba si te afecta y migra a Opus 5.5 en sesiones, ajustes y CI.

Probado con Claude Code 2.1.316 · revisado 2026-11-01

Ver los archivos en GitHub Gratis · licencia MIT

El problema

Desde el 30-oct-2026 el modo rápido (fast mode) de Opus 4.8 está retirado, y el 30-nov-2026 se elimina: a partir de ese día las peticiones en modo rápido con Opus 4.8 darán error y no pasarán solas a Opus 4.8 normal. Si usas /fast con Opus 4.8, en una sesión, en tus ajustes o en un script de CI, eso dejará de funcionar.

La solución

Pasa a Opus 5.5, que ya tiene el modo rápido disponible (no en vista previa) y además más barato por token. Primero comprueba si te afecta, luego migra en sesiones, ajustes y scripts, y ten en cuenta lo que cambia al hacerlo.

1. Qué cambia y a quién afecta

El modo rápido no es otro modelo: es una configuración de Opus que responde hasta 2,5 veces más rápido a un precio por token más alto. Según la documentación oficial, funciona en Opus 5.5, Opus 5 y Opus 4.8, no en Sonnet ni Haiku; en Opus 5.5 está disponible y en Opus 5 y 4.8 es una vista previa de investigación. La versión 2.1.316 del CHANGELOG añade el aviso: el modo rápido de Opus 4.8 queda retirado desde el 30-oct-2026 y se eliminará el 30-nov-2026; después, esas peticiones devolverán error y no volverán a Opus 4.8 estándar.

Te afecta solo si cumples las dos condiciones:

  • usas el modo rápido: el icono ↯ junto al prompt, "fastMode": true en tus ajustes o --settings con fastMode en scripts;
  • tu modelo es Opus 4.8: lo fijaste con /model claude-opus-4-8, --model, ANTHROPIC_MODEL, la clave model o ANTHROPIC_DEFAULT_OPUS_MODEL.

No te afecta si usas el alias opus en la API de Anthropic (ya apunta a Opus 5.5), si no usas el modo rápido, o si trabajas en Bedrock, Agent Platform de Google Cloud o Foundry, donde el modo rápido no está disponible.

2. Compruébalo en 1 minuto

Dentro de Claude Code:

  1. /status muestra versión, modelo y cuenta; la fila Login method te dice si usas suscripción (por ejemplo «Claude Max account») o una clave de API.
  2. /fast sin argumentos te deja ver si el modo rápido está activado o no; con él activo verás «↯» junto al prompt.
  3. /model te enseña el modelo actual.

Fuera de la sesión, busca fijaciones a Opus 4.8 en tus ajustes y variables: en ~/.claude/settings.json y en .claude/settings.json o settings.local.json de tus proyectos, las claves "model" y "fastMode"; en tu shell, ANTHROPIC_MODEL y ANTHROPIC_DEFAULT_OPUS_MODEL; y en scripts o CI, cualquier claude -p con --model claude-opus-4-8 junto a --settings '{"fastMode": true}'. Este grep lo revisa todo de una vez (cambia ~/proyectos por la carpeta donde tengas tus proyectos):

grep -rn --include='settings*.json' -e 'claude-opus-4-8' -e 'fastMode' ~/.claude ~/proyectos 2>/dev/null
env | grep -E 'ANTHROPIC_(DEFAULT_OPUS_)?MODEL'
grep -rn 'claude-opus-4-8' ~/proyectos --include='*.sh' --include='*.yml' --include='*.yaml' 2>/dev/null

Si no aparece claude-opus-4-8 en ningún sitio y tu modelo es opus u Opus 5.5, no tienes que hacer nada. Recuerda que el modelo elegido con --model o ANTHROPIC_MODEL solo vale para esa sesión, mientras que /model lo guarda como predeterminado.

3. Migrar: tres pasos

Paso 1, cambia el modelo. En la sesión: /model opus (en la API de Anthropic el alias resuelve a Opus 5.5) o, para fijar la versión exacta, /model claude-opus-5-5. Si lo tenías fijado en ajustes o variables, cambia allí claude-opus-4-8 por claude-opus-5-5 o por el alias opus, o elimina la fijación. Recuerda que un model en ajustes de proyecto o gestionados, o ANTHROPIC_MODEL en tu shell, se impone a tu elección de /model en cada arranque.

~/.claude/settings.json, antes y después:

// antes
{ "model": "claude-opus-4-8", "fastMode": true }
// después
{ "model": "claude-opus-5-5", "fastMode": true }

Paso 2, activa el modo rápido al principio de una sesión nueva: /fast, Espacio para activarlo y Enter para confirmar, o "fastMode": true en tus ajustes de usuario. Verás «Fast mode ON» y el icono ↯. Desde la 2.1.280, Opus 5.5 es el modelo por defecto del modo rápido: si activas /fast con un modelo que no lo admite, Claude Code cambia a Opus.

/status              # modelo y método de inicio de sesión
/model claude-opus-5-5   # o /model opus
/effort status       # Opus 5.5 empieza en medium
/effort high         # opcional, si quieres el nivel que tenías en 4.8
/fast                # Espacio + Enter -> «Fast mode ON» e icono ↯

Paso 3, actualiza scripts y CI. En claude -p, /fast solo funciona si lanzas la sesión con fastMode en --settings (2.1.205 o posterior), así que cambia el --model de esos comandos:

# antes (dará error a partir del 30-nov-2026)
claude -p --model claude-opus-4-8 --settings '{"fastMode": true}' "Revisa los tests"
# después
claude -p --model claude-opus-5-5 --settings '{"fastMode": true}' "Revisa los tests"

Si necesitas seguir con Opus 4.8 por algún motivo, desactiva el modo rápido (/fast off): la retirada afecta solo al modo rápido.

4. Lo que cambia al pasar a Opus 5.5: precio y esfuerzo

Precio del modo rápido según la documentación oficial, por millón de tokens:

ModeloEntradaSalidaEstado del modo rápido
Opus 5.58 USD40 USDDisponible
Opus 510 USD50 USDVista previa de investigación
Opus 4.810 USD50 USDRetirado; error desde el 30-nov-2026

El precio es plano en toda la ventana de 1M de tokens. Con suscripción Pro, Max, Ultra, Team o Enterprise, el modo rápido no entra en los límites del plan: se paga solo con créditos de uso, aunque te quede uso del plan, y necesitas tenerlos activados (si no, /fast dice «Fast mode requires usage credits»). En Team y Enterprise además lo tiene que activar un Owner. En Console, el modo rápido de Opus 5.5 depende del nivel de uso de tu organización.

La trampa del esfuerzo: Opus 4.8 tiene esfuerzo high por defecto y Opus 5.5 medium. Además, un effortLevel de nivel superior en tus ajustes de usuario (el formato antiguo) no cuenta para Opus 5.5. Si notas respuestas menos profundas tras migrar, comprueba con /effort status y elige el nivel con /effort high (Enter lo guarda como predeterminado para ese modelo; s, solo para la sesión). Modo rápido y esfuerzo se combinan: más rápido con menos esfuerzo para tareas sencillas.

5. Activar el modo rápido sin pagar de más

La primera vez que activas el modo rápido en una conversación pagas, al precio del modo rápido y sin caché, todo el contexto acumulado hasta ese momento. Cuanto más avanzada esté la conversación, más cuesta, así que la documentación recomienda activarlo al empezar la sesión. Modo rápido y velocidad estándar tienen cachés separadas: cada cambio posterior vuelve a leer sin caché parte o toda la conversación. Lo mismo pasa al cambiar de modelo: cada modelo tiene su propia caché (ver límite de uso).

Por eso, la migración ideal es: cierra la sesión vieja, abre una nueva con Opus 5.5 y activa /fast antes del primer mensaje.

¿Dónde ves lo gastado? En Pro, Max y Ultra, en claude.ai > Settings > Usage, sección Usage credits (incluye el modo rápido sin desglosarlo); en Team y Enterprise, en la fila de créditos de /usage; en Console, en Usage y Cost agrupando por «Speed (Research Preview)».

Para equipos con varias sesiones simultáneas, fastModePerSessionOptIn: true hace que cada sesión empiece con el modo rápido apagado:

{
  "fastModePerSessionOptIn": true
}

Si te quedas sin créditos a mitad de sesión, Claude Code reintenta a velocidad estándar y lo avisa con «Fast mode disabled · usage credits exhausted».

6. Si algo falla después de migrar

Los mensajes que puedes ver y qué hacer con cada uno están en «Errores típicos», más abajo. Si a partir del 30-nov ves errores en un script antiguo, busca un --model claude-opus-4-8 olvidado junto al modo rápido con el grep del paso 2.

Compruébalo

Después de migrar, abre una sesión nueva y ejecuta /status (modelo), /effort status y /fast sin confirmar. Lo que probamos el 1-nov-2026 con Claude Code 2.1.316 en Linux: /effort status con --model claude-opus-5-5 devolvió «auto (currently medium)», lo que confirma el esfuerzo por defecto; y claude -p "/fast" respondió «Fast mode unavailable: Fast mode is not available in the Agent SDK», como describe la documentación para -p sin fastMode en --settings. No activamos el modo rápido, porque se cobra con créditos de uso (gasto real), y el error posterior al 30-nov no se puede reproducir antes de esa fecha: eso lo contamos tal como lo anuncia el CHANGELOG.

Por qué funciona

El modo rápido es una configuración por modelo, y la retirada solo afecta a la combinación Opus 4.8 + modo rápido. Cambiar el modelo a Opus 5.5 (o al alias opus) en todos los sitios donde lo fijaste mantiene el modo rápido sin tocar nada más. Activarlo al empezar la sesión evita pagar todo el contexto acumulado sin caché. Fuentes: modo rápido, configuración de modelos, caché al activar el modo rápido, comandos y el CHANGELOG.

Errores típicos

  • «Fast mode requires usage credits» → con suscripción, el modo rápido solo se paga con créditos de uso → actívalos en claude.ai > Settings > Usage o con /usage-credits.
  • «Fast mode has been disabled by your organization» → el modo rápido no está activado en tu organización, o unos ajustes gestionados ponen fastMode: false o exigen activación por sesión → habla con tu administrador.
  • «is not in your organization's allowed models» → la lista availableModels de tu organización excluye ese Opus → pide que lo añadan o usa uno permitido.
  • «Fast mode unavailable due to network connectivity issues» → la comprobación de disponibilidad va directa a api.anthropic.com y tu red la bloquea (típico detrás de un gateway) → la documentación propone permitir esa salida o CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS=1.
  • «Fast mode is not available in the Agent SDK» en claude -p → es lo esperado si no lanzaste la sesión con --settings '{"fastMode": true}' → añádelo al comando.
  • Errores en un script antiguo a partir del 30-nov → un --model claude-opus-4-8 olvidado junto al modo rápido → cámbialo por claude-opus-5-5.
  • Eliges Opus 5.5 con /model y al reiniciar vuelve a 4.8 → un model en ajustes de proyecto o gestionados, o ANTHROPIC_MODEL en tu shell, se impone en cada arranque → cámbialo allí.
  • El icono ↯ se pone gris → has llegado al límite propio del modo rápido → sigue a velocidad normal; se reactiva solo al acabar la espera.

Preguntas frecuentes

¿Tengo que hacer algo si no uso /fast?

No. La retirada que anuncia el CHANGELOG es solo del modo rápido en Opus 4.8; no anuncia cambios para Opus 4.8 a velocidad normal.

¿Qué pasa exactamente el 30 de noviembre?

Las peticiones en modo rápido con Opus 4.8 devolverán error y no pasarán solas a Opus 4.8 estándar.

¿El modo rápido de Opus 5.5 es más caro?

Según la documentación oficial es más barato que el de 4.8: 8/40 USD por millón de tokens de entrada/salida frente a 10/50. Sigue costando más que la velocidad normal.

¿El modo rápido gasta mi límite de Pro o Max?

No entra en los límites del plan: se cobra directamente de los créditos de uso, aunque te quede uso del plan (ver cuánto cuesta Claude Code).

¿Y si me paso a Opus 5 en vez de 5.5?

El CHANGELOG pide migrar a Opus 5.5. En Opus 5 el modo rápido sigue en vista previa de investigación, a 10/50 USD.

¿Por qué Opus 5.5 «piensa menos» que mi Opus 4.8?

Su esfuerzo por defecto es medium (en 4.8, high) y un effortLevel antiguo en tus ajustes de usuario no se le aplica. Usa /effort high.

¿Puedo usar el modo rápido en Bedrock o Vertex?

No: según la documentación, solo en la API de Anthropic (Console) y en planes de suscripción con créditos de uso.
