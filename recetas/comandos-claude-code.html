Comandos de Claude Code: chuleta de slash, atajos y flags

Chuleta de Claude Code al día: comandos /, atajos de teclado y flags de terminal por grupos, con qué hace cada uno y cuándo usarlo. Lista para copiar.

Probado con Claude Code 2.1.316 · revisado 2026-11-02

Resumen

Claude Code tiene más de cien comandos /, decenas de atajos y otras tantas opciones de terminal. Esta chuleta reúne los que de verdad se usan en el día a día, agrupados por para qué sirven: sesión y contexto, modelo y coste, permisos y modos, proyecto y memoria, extensiones, diagnóstico, atajos de teclado y flags de línea de comandos. Cada fila dice qué hace en una frase y cuándo te conviene.

Todo está comprobado contra la documentación oficial y contra claude --help en Claude Code 2.1.316. Escribe / en una sesión para ver la lista completa de tu versión (incluidas tus skills), y ? con el cuadro vacío para ver los atajos.

Sesión y contexto

ComandoQué haceCuándo usarlo
/clear [nombre]Empieza una conversación nueva con el contexto vacío (alias /reset y /new)Al cambiar de tarea; el nombre etiqueta la anterior en /resume
/compact [instrucciones]Resume la conversación para liberar contexto sin salir de ellaCuando el contexto se llena pero quieres seguir con la misma tarea
/contextMuestra en una cuadrícula qué ocupa la ventana de contexto, con sugerenciasAntes de decidir entre /clear y /compact, o si Claude va lento
/resume [sesión]Retoma una conversación por ID o nombre, o abre el selectorPara volver a una tarea de ayer
/rename [nombre]Pone nombre a la sesión actual (sin nombre, lo genera)Para encontrarla luego con /resume o claude -r
/branch [nombre]Crea una rama de la conversación en este punto y te cambia a ellaPara probar otro enfoque sin perder lo que llevas
/rewindVuelve la conversación y/o el código a un punto anterior (alias /checkpoint, /undo)Cuando Claude tomó un mal camino y quieres deshacer sus cambios
/btw [pregunta]Hace una pregunta lateral sin añadirla a la conversaciónPara una duda rápida que no debe ensuciar el contexto
/copy [N]Copia la última respuesta (o la N-ésima) al portapapelesPara pegar un bloque de código o una respuesta fuera
/export [archivo]Exporta la conversación como texto planoPara guardar o compartir una sesión
/recapGenera un resumen de una línea de la sesiónAl volver de una pausa
/exitSale de Claude Code (alias /quit)Al terminar
/context
/compact conserva solo la decisión sobre la API y los archivos tocados
/clear arreglo-login
/resume arreglo-login

La diferencia entre limpiar y compactar, y la compactación en reposo, están en /clear vs /compact.

Modelo y coste

ComandoQué haceCuándo usarlo
/model [modelo]Cambia el modelo y lo guarda como predeterminado; en el selector, s lo cambia solo para esta sesiónPara pasar a un modelo más capaz o más barato según la tarea
/effort [nivel]Fija el nivel de esfuerzo: de low a xhigh, max o auto; status lo muestraMás esfuerzo para problemas difíciles, menos para tareas mecánicas
/fast [on|off]Activa o desactiva el modo rápidoCuando la velocidad importa más que el coste
/usageMuestra coste de la sesión, límites del plan y estadísticas (alias /cost y /stats)Para saber cuánto te queda antes del límite
/rate-limit-optionsMuestra cómo seguir trabajando cuando un límite de uso bloquea una peticiónAl chocar con el límite de tu plan
/model sonnet
/effort high
/usage

Qué modelo elegir para cada tarea está en Opus vs Sonnet vs Haiku, el modo rápido en Opus 4.8 y el modo rápido y cómo estirar tu cuota en Límite de uso.

Permisos y modos

ComandoQué haceCuándo usarlo
/permissionsAbre las reglas allow, ask y deny por ámbito, y las denegaciones recientes del modo automático (alias /allowed-tools)Para dejar de aprobar el mismo comando una y otra vez
/plan [descripción]Entra en modo plan desde el cuadro, opcionalmente con la tareaAntes de un cambio grande: acordar el enfoque sin tocar código
/sandboxActiva o desactiva el modo sandbox (solo en plataformas compatibles)Para aislar los comandos de Bash del resto del sistema
/fewer-permission-promptsSkill incluida: revisa tus transcripciones y propone una lista de permitidos para .claude/settings.jsonCuando aprobar comandos de solo lectura te frena
/add-dir <ruta>Añade otra carpeta de trabajo a la sesiónCuando la tarea toca un repositorio vecino
/plan migra el login a OAuth sin tocar la base de datos
/permissions

Las reglas a fondo están en Permisos de Claude Code, el modo plan en Modo plan y el clasificador en Modo automático.

/cd <ruta>Mueve la sesión a otra carpeta conservando la conversaciónPara seguir la misma tarea en otro directorio

Extensiones: skills, plugins, MCP y hooks

ComandoQué haceCuándo usarlo
/skillsLista las skills disponibles; t ordena por tokensPara ver qué tienes instalado y qué pesa
/reload-skillsVuelve a leer las carpetas de skills y comandos sin reiniciarTras crear o editar una skill durante la sesión
/skill-doctorMuestra cuánto contexto cuesta cada skill y cuánto se usaPara decidir cuáles desactivar
/plugin [subcomando]Abre el gestor de plugins o actúa directo (list, install, enable, disable)Para instalar o apagar un plugin
/reload-pluginsRecarga los plugins activos para aplicar cambios sin reiniciarTras instalar o modificar un plugin
/mcpGestiona las conexiones y la autenticación de los servidores MCP; reconnect all reintenta los caídosCuando un servidor MCP no responde o pide login
/hooksMuestra la configuración de hooksPara comprobar qué se ejecuta en cada evento
/agentsEn 2.1.316 solo recuerda que pidas a Claude crear el subagente o edites .claude/agents/Para no buscar el menú antiguo, que desapareció tras la 2.1.197
/statuslineConfigura la barra de estado, describiéndola o copiando tu prompt de shellPara ver modelo, contexto y límites siempre a la vista
/output-style [estilo]Lista los estilos de salida o cambia a unoPara respuestas más breves o más didácticas

Desde la terminal, sin abrir sesión:

# Añadir un servidor MCP remoto y listar los configurados
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
claude mcp list
# Instalar un plugin y ver qué trae y cuánto contexto cuesta
claude plugin install <plugin>
claude plugin details <plugin>

Cada pieza tiene su receta: primera skill, crear un plugin, MCP para programadores, hooks de seguridad, subagentes y statusline. Si dudas cuál usar, mira qué pieza usar.

/debug [descripción]Skill incluida: activa el registro de depuración y lo analizaPara un fallo concreto que puedes reproducir
/statusMuestra versión, modelo, cuenta y conectividadPara confirmar con qué cuenta y modelo trabajas
/configAbre los ajustes (tema, modelo, estilo…); acepta clave=valorPara cambiar una preferencia sin editar JSON
/tasksMuestra y gestiona el trabajo en segundo plano de la sesión (alias /bashes)Para ver o parar un comando o subagente en segundo plano
/release-notesAbre el changelog por versiónTras actualizar, para ver qué cambió
/bug [informe]Reporta un error o comparte la conversación, con pantalla de consentimientoPara avisar a Anthropic de un fallo

Atajos de teclado

AtajoQué haceCuándo usarlo
EscInterrumpe a Claude o cierra un diálogo, conservando lo hechoCuando va por mal camino y quieres redirigirlo
Esc EscCon texto, borra el borrador; con el cuadro vacío, abre el menú de rebobinadoPara deshacer sin escribir /rewind
Shift+TabCambia de modo de permisos: Manual, acceptEdits, plan y, si están disponibles, bypassPermissions y autoPara entrar en modo plan o aceptar ediciones en un segundo
Ctrl+CInterrumpe; sin nada en marcha, borra el cuadro y una segunda pulsación salePara parar o salir
Ctrl+RBusca hacia atrás en el historial de promptsPara repetir un prompt largo
Ctrl+OAbre el visor de la transcripción con el detalle de herramientasPara ver qué ejecutó exactamente
Ctrl+BPasa a segundo plano los comandos de Bash y agentes en marcha (en tmux, dos veces)Con un servidor o tests largos que no quieres esperar
Ctrl+TMuestra u oculta la lista de tareas de ClaudePara seguir el avance de una tarea larga
Ctrl+GAbre el prompt en tu editor de textoPara escribir un prompt largo con calma
Ctrl+VPega una imagen del portapapeles (Alt+V en Windows y WSL)Para enseñarle una captura de un error
Ctrl+J o \ + EnterSalto de línea sin enviar, en cualquier terminalPara prompts de varias líneas
Alt+PCambia de modelo sin borrar lo escrito (Option+P en macOS)A mitad de un prompt
Alt+TActiva o desactiva el pensamiento extendido (Option+T en macOS); no afecta a los modelos 5.5 ni Fable, que siempre lo usanCon modelos anteriores
! al inicioModo shell: ejecuta el comando y añade su salida a la sesiónPara que Claude vea la salida de git status o tus tests
@Autocompleta rutas de archivo para mencionarlasPara señalar el archivo exacto
? con el cuadro vacíoMuestra u oculta el panel de atajosPara descubrir el resto
! git status
Revisa @src/auth/login.ts y explica por qué falla el test

En macOS, los atajos con Alt necesitan configurar Option como Meta en tu terminal. Si Shift+Enter no hace salto de línea en tu editor, /terminal-setup lo instala en VS Code, Cursor, Alacritty o Zed, y /keybindings abre tu archivo de atajos para cambiarlos.

Flags de línea de comandos más usados

FlagQué haceCuándo usarlo
-p, --printResponde y sale, sin modo interactivoEn scripts, cron y tuberías
-c, --continueCarga la conversación más reciente de esta carpetaPara seguir donde lo dejaste
-r, --resume [sesión]Retoma una sesión por ID o nombre, o abre el selectorPara volver a una sesión concreta
-n, --name <nombre>Pone nombre a la sesiónPara retomarla luego con claude -r <nombre>
--model <modelo>Elige el modelo de esta sesión (sonnet, opus, haiku, fable o un nombre completo)Para empezar ya con el modelo adecuado
--effort <nivel>Fija el esfuerzo de esta sesión, sin guardarloPara un script que no necesita pensar mucho
--permission-mode <modo>Empieza en un modo de permisos (default, acceptEdits, plan, auto, dontAsk, bypassPermissions)Para abrir directamente en modo plan
-w, --worktree [nombre]Abre la sesión en un git worktree aisladoPara varias tareas en paralelo sin pisarse
--add-dir <rutas>Da acceso a carpetas adicionalesCuando la tarea cruza dos repositorios
--allowedTools <herramientas>Herramientas que se ejecutan sin pedir permisoEn -p, para que el script no se quede esperando
--output-format <formato>Salida text, json o stream-json (solo con -p)Para procesar la respuesta con otro programa
--max-turns <n>Limita los turnos del agente (solo con -p)Para que un script no se alargue sin control
--max-budget-usd <importe>Para cuando el gasto estimado llega al tope (solo con -p)Al pagar por uso con clave de API
--append-system-prompt <texto>Añade texto al final del prompt de sistemaPara una regla puntual sin tocar CLAUDE.md
--debug [filtro]Activa el modo depuración, con filtro opcional (--debug=hooks,mcp)Cuando un hook o un MCP no se comporta
--safe-modeArranca con todas las personalizaciones desactivadasPara saber si el fallo viene de tu configuración
# Una pregunta y salir
claude -p "explica qué hace este proyecto"
# Pasarle un archivo por tubería
cat logs.txt | claude -p "explica el error"
# Seguir la última conversación de esta carpeta
claude -c
# Retomar una sesión por nombre con un prompt nuevo
claude -r "auth-refactor" "termina este PR"
# Empezar en modo plan con un modelo concreto
claude --model opus --permission-mode plan
# Script acotado con salida JSON
claude -p "lista los TODO del repo" --output-format json --max-turns 3
# Trabajo en paralelo en un worktree
claude -w feature-auth

claude -p en scripts y cron está en Claude Code headless, los worktrees en varios agentes en paralelo y el control desde el móvil (--remote-control o /remote-control) en Remote Control.

Qué comprobamos

En Linux con Claude Code 2.1.316 contrastamos cada comando, atajo y flag con la documentación oficial (comandos, modo interactivo y referencia de la CLI) y con claude --help, claude mcp --help y claude plugin --help. Solo consultamos la ayuda: no ejecutamos los comandos que gastan uso. --max-turns está en la documentación pero no aparece en claude --help de esta versión. Los comandos / que no ves en tu menú pueden depender de tu plan, tu plataforma o tu versión.

Preguntas frecuentes

¿Cómo veo todos los comandos de Claude Code?

Escribe / en una sesión: aparece la lista completa de tu versión, incluidas tus skills y las de tus plugins, y puedes filtrar escribiendo. /help muestra la ayuda, y claude --help las opciones de terminal.

¿Qué diferencia hay entre /clear y /compact?

/clear empieza una conversación nueva con el contexto vacío; /compact resume la actual para liberar espacio y seguir con la misma tarea. Lo explicamos con ejemplos en /clear vs /compact.

¿Puedo crear mis propios comandos?

Sí: cualquier skill en .claude/skills/<nombre>/SKILL.md (o un archivo en .claude/commands/) crea /nombre. Tienes cinco listos para copiar en el pack de comandos y el paso a paso en primera skill.

¿Cómo retomo una conversación anterior?

claude -c carga la más reciente de la carpeta actual y claude -r abre el selector o retoma una por ID o nombre. Dentro de una sesión, /resume hace lo mismo.
