Instalar Claude Code en Windows: nativo, WSL y errores típicos

Cómo instalar Claude Code en Windows 10 u 11 desde PowerShell, CMD o WSL, arreglar el PATH, iniciar sesión y resolver los errores más comunes.

Probado con Claude Code 2.1.316 · revisado 2026-10-31

El problema

Claude Code funciona en Windows, pero hay tres maneras de instalarlo (PowerShell, CMD o WSL) y cada una usa un comando distinto. Si copias el comando equivocado, aparecen errores como 'irm' is not recognized o The token '&&' is not a valid statement separator. Si el instalador termina bien pero la carpeta no está en el PATH, aparece 'claude' is not recognized. Esta receta te dice qué opción elegir, qué comando pegar y cómo arreglar cada error.

Cómo se comprobó: los comandos y los mensajes de error salen de la documentación oficial de instalación y de la guía oficial de problemas de instalación, revisadas el 31-oct-2026. claude --version y claude doctor se probaron en Linux con la versión 2.1.316. No pudimos probarlo en un Windows real: si algo no coincide en tu equipo, sigue la guía oficial de problemas de instalación.

La solución

1. Comprueba los requisitos

  • Windows 10 1809 o posterior, o Windows Server 2019 o posterior, de 64 bits.
  • 4 GB de RAM o más, procesador x64 o ARM64 y conexión a internet.
  • Una cuenta Pro, Max, Ultra, Team, Enterprise o Console. El plan gratis de claude.ai no incluye Claude Code.
  • Estar en un país donde Anthropic da servicio.

No necesitas Node.js ni permisos de administrador.

2. Elige: Windows nativo o WSL

OpciónQué necesitasSandboxCuándo usarla
Windows nativoNada; Git para Windows es opcionalNoProyectos y herramientas de Windows
WSL 2WSL 2 activadoSíHerramientas de Linux o comandos en sandbox
WSL 1WSL 1 activadoNoSolo si no puedes usar WSL 2

Si dudas, empieza por Windows nativo.

3a. Windows nativo: abre la terminal correcta

Busca «PowerShell» en el menú Inicio y abre Windows PowerShell, no la entrada que termina en (x86). Para saber en qué terminal estás, mira el inicio de la línea: PS C:\Users\TuNombre> es PowerShell y C:\Users\TuNombre> (sin PS) es CMD.

En PowerShell:

irm https://claude.ai/install.ps1 | iex

En CMD:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

El instalador no muestra el progreso mientras descarga, así que espera a que termine. Cuando acabe, cierra la terminal y abre una nueva. La ventana donde instalaste conserva el PATH viejo.

Otra opción es WinGet. Ten en cuenta que esta instalación no se actualiza sola:

winget install Anthropic.ClaudeCode

3b. WSL: instala dentro de Linux

Abre tu distribución de WSL (por ejemplo, Ubuntu) y ejecuta el instalador de Linux dentro de esa terminal, no en PowerShell:

curl -fsSL https://claude.ai/install.sh | bash

En WSL, claude se instala y se ejecuta dentro de la terminal de Linux. No necesitas Git para Windows.

4. (Windows nativo) Instala Git para Windows si quieres Bash

Sin Git para Windows, Claude Code ejecuta los comandos con su herramienta de PowerShell. Si instalas Git para Windows, marca «Add to PATH» durante la instalación. Así Claude Code puede usar Git Bash para su herramienta Bash, que también necesita la herramienta Monitor. Si Git está instalado en una carpeta poco habitual y Claude Code no lo encuentra, indica la ruta en %USERPROFILE%\.claude\settings.json:

{
  "env": {
    "CLAUDE_CODE_GIT_BASH_PATH": "C:\\Program Files\\Git\\bin\\bash.exe"
  }
}

La ruta debe terminar en bash.exe, sh.exe, bash o sh. Si pones git-bash.exe, Claude Code no la usa. Para saber dónde está tu Git, ejecuta where.exe git en PowerShell.

5. Inicia sesión

Abre una terminal en la carpeta de tu proyecto y ejecuta:

claude

Se abre el navegador para que inicies sesión. Si no se abre, pulsa c para copiar la URL de inicio de sesión y pégala en el navegador. En WSL2, si el navegador no logra volver a localhost, el navegador te muestra un código: pégalo en la terminal donde dice Paste code here. Si pegar no funciona, prueba con clic derecho o Shift+Insert en Windows Terminal, o usa claude auth login.

En Windows, las credenciales se guardan en %USERPROFILE%\.claude\.credentials.json.

Compruébalo

En una terminal nueva:

claude --version

Si todo está bien, verás el número de versión. Esta es la salida real en nuestro equipo (Linux):

2.1.316 (Claude Code)

Para una revisión más completa, sin abrir una sesión:

claude doctor

Esta es la salida real en Linux. En Windows cambian la plataforma y la ruta, pero la estructura es la misma:

Si doctor encuentra un problema, lo muestra como advertencia y sugiere cómo arreglarlo. Dentro de una sesión, /doctor hace una revisión más amplia y /status muestra con qué cuenta iniciaste sesión.

Por qué funciona

El instalador nativo descarga un único ejecutable, claude.exe, en %USERPROFILE%\.local\bin. En macOS, Linux y WSL lo deja en ~/.local/bin/claude. No usa Node.js ni npm, y se actualiza solo en segundo plano. El instalador no cambia el PATH: si la carpeta no está en él, lo avisa en Setup notes: y muestra cómo arreglarlo. Esa es la causa de casi todos los 'claude' is not recognized. Detalles en Configuración avanzada y Solucionar problemas de instalación.

Arreglar el PATH (PowerShell)

Primero comprueba que el ejecutable existe:

Test-Path "$env:USERPROFILE\.local\bin\claude.exe"

Si sale True, añade la carpeta al PATH de tu usuario. Este cambio es permanente:

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

Cierra la terminal, abre una nueva y ejecuta claude --version. Si usas la terminal de VS Code u otro editor, cierra el editor por completo y vuelve a abrirlo, porque la terminal toma el PATH del editor. En CMD, añade %USERPROFILE%\.local\bin a la variable PATH de usuario desde Variables de entorno. Si Test-Path sale False, no hay instalación nativa: vuelve al paso 3a.

Borrar la carpeta de descargas y reinstalar

Remove-Item -Recurse -Force "$env:USERPROFILE\.claude\downloads"
irm https://claude.ai/install.ps1 | iex

Restaurar claude.exe después de una actualización fallida

Get-ChildItem "$env:USERPROFILE\.local\bin\claude.exe.old.*" | Sort-Object Name | Select-Object -Last 1 | Rename-Item -NewName claude.exe

Si no hay ningún archivo claude.exe.old.*, reinstala con irm https://claude.ai/install.ps1 | iex.

Preguntas frecuentes

¿Hay Claude Code para Windows?

Sí. Funciona en Windows 10 (1809 o posterior) y Windows 11 de 64 bits, de forma nativa desde PowerShell o CMD, o dentro de WSL. Si prefieres no usar la terminal, también existe la app de escritorio.

¿Es mejor instalarlo en PowerShell o en WSL?

Si tus proyectos y herramientas son de Windows, instálalo de forma nativa. Si trabajas con herramientas de Linux o quieres ejecutar comandos en sandbox, usa WSL 2, que es la única opción de Windows con sandbox.

¿Necesito Node.js o npm?

No. El instalador nativo descarga un ejecutable propio. npm sigue siendo una opción, pero da más problemas en Windows, como los de la política de ejecución o el Node de Windows dentro de WSL.

¿Necesito ser administrador?

No. El instalador nativo instala en tu carpeta de usuario y no pide permisos de administrador.

¿Puedo usar Claude Code con el plan gratis?

No. El plan gratis de claude.ai no incluye Claude Code. Necesitas Pro, Max, Ultra, Team, Enterprise, una cuenta de Console o un proveedor como Amazon Bedrock.

¿Cómo lo actualizo?

La instalación nativa se actualiza sola. Para actualizar al momento, ejecuta claude update. Si instalaste con WinGet, ejecuta winget upgrade Anthropic.ClaudeCode.
