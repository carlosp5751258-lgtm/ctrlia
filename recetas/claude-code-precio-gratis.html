¿Claude Code es gratis? Precio y qué plan elegir (2026)

Claude Code no es gratis: va incluido en Pro, Max y Ultra o se paga por tokens con la API. Precios oficiales, qué plan elegir y cómo gastar menos.

Probado con Claude Code 2.1.316 · revisado 2026-10-31

El problema

Quieres usar Claude Code y no tienes claro si es gratis, cuánto cuesta ni qué plan te conviene. En internet hay cifras viejas y contradictorias, y las búsquedas por país («claude code precio méxico», «argentina», «españa»…) dan precios que nadie comprueba. Aquí tienes solo lo que dicen hoy las páginas oficiales de Anthropic, con la fecha en que se consultaron.

La solución

1. La respuesta corta: no, Claude Code no es gratis

El plan Free de Claude ($0) sirve para el chat en web, escritorio y móvil, pero no incluye Claude Code. En la página de precios, la línea «Claude Code included» aparece a partir de Pro (claude.com/pricing, consultado el 31-oct-2026).

El programa en sí se instala sin pagar, pero para usarlo necesitas una de estas dos cosas:

  • Una suscripción que lo incluya (Pro, Max, Ultra, Team o Enterprise): pagas una cuota fija y tienes un margen de uso que se renueva.
  • Una clave de API (cuenta de Claude Console): pagas por cada token que consume.

2. Planes de suscripción que incluyen Claude Code

Precios en dólares estadounidenses, sin impuestos (claude.com/pricing, consultado el 31-oct-2026):

PlanPrecioUso incluido
Free$0Sin Claude Code
Pro$20 al mes, o $17 al mes con pago anual ($200 por adelantado)«Más uso que Free», cada 5 horas y cada semana
Max$100 al mes5 veces el uso de Pro, cada 5 horas y cada semana
Ultra$200 al mes10 veces el uso de Pro por semana y sin límite de 5 horas (cuentas verificadas)
Team, plaza estándar$20 por plaza al mes con pago anual, $25 con pago mensualPara equipos de 2 a 150 personas

EnterpriseUS$20 por plaza al mes con pago anual, mínimo 20 plazas, más el uso a tarifas de APISegún modelo y tarea

Cómo funcionan los límites de las suscripciones (centro de ayuda, consultado el 31-oct-2026):

  • Pro y Max tienen un límite por sesión de 5 horas y otro semanal. Ultra tiene el semanal, y las cuentas Ultra verificadas no tienen el de 5 horas.
  • Los límites se comparten entre el chat de Claude y Claude Code: todo lo que haces en los dos cuenta contra el mismo margen.
  • Anthropic no publica un número fijo de mensajes por cada 5 horas. Depende del modelo, del tamaño de tu proyecto y de lo largas que sean tus sesiones.

Si llegas al límite, puedes esperar a que se reinicie o activar los créditos de uso (usage credits): se pagan por adelantado, se cobran a tarifas de API y les puedes poner un tope mensual (centro de ayuda, consultado el 31-oct-2026). Desde Claude Code se abren con /usage-credits.

3. Pago por uso con la API

Con una cuenta de Claude Console pagas por millón de tokens (MTok). Precios de lista (claude.com/pricing, consultado el 31-oct-2026):

ModeloEntradaSalida
Opus 5.5$4 / MTok$20 / MTok
Sonnet 5.5$2 / MTok$10 / MTok
Haiku 5.5 (prompts de hasta 100K tokens)$0.10 / MTok$0.50 / MTok
Haiku 5.5 (prompts de más de 100K tokens)$0.50 / MTok$2.50 / MTok

¿Cuánto es eso en la práctica? La documentación oficial da esta referencia de empresas: unos $13 por desarrollador y día activo y $150-250 por desarrollador al mes, y el 90 % de los usuarios queda por debajo de $30 por día activo (docs de costes, consultado el 31-oct-2026). Tu gasto puede ser muy distinto: cambia con el modelo, el tamaño del código y lo que automatices.

Para pagar con API, arranca claude, escribe /login y elige la cuenta de Console. Si tienes definida la variable ANTHROPIC_API_KEY, Claude Code usa esa clave en lugar de tu suscripción y te cobra por API, aunque pagues Pro o Max.

4. Qué plan elegir

Elige según cuánto lo uses, no según el precio más bajo:

  • Quieres probarlo o lo usas unas horas por semana: Pro. Es la entrada más barata a Claude Code.
  • Lo usas todos los días y te topas con el límite de 5 horas: Max.
  • Pasas sesiones muy largas o lanzas tareas que corren horas: Ultra (sin límite de 5 horas en cuentas verificadas).
  • Equipo de 2 a 150 personas con facturación conjunta: Team (plaza estándar o premium según el uso de cada uno).
  • Uso esporádico, scripts, CI o quieres pagar solo lo que gastas: API. Ponle un límite de gasto en el espacio de trabajo de Console: con la API no hay techo salvo el que pongas tú.

Si tienes dudas, empieza por Pro con pago mensual y mira /usage durante una o dos semanas antes de subir de plan.

5. Cómo ver tu consumo

Todos estos comandos se escriben dentro de una sesión de Claude Code (referencia de comandos, consultado el 31-oct-2026):

ComandoQué muestra
/usageCoste de la sesión, límites de tu plan y estadísticas de actividad. En planes de pago, qué consume tu margen (skills, subagentes, MCP) con recomendaciones
/costAlias de /usage
/statsAlias de /usage, abre la pestaña de estadísticas
/statusVersión, modelo y cuenta con la que has entrado (suscripción o API)
/contextQué ocupa tu ventana de contexto ahora mismo
/insightsInforme HTML sobre cómo trabajas, con sugerencias

Dos detalles de la documentación de costes:

  • En /usage, la cifra en dólares de la sesión es una estimación a precio de lista y está pensada para quien paga por API. Si tienes Pro, Max o Ultra, no es lo que te cobran: mira las barras de uso del plan.
  • Si en el pie de /usage aparece f to fix, pulsa f y Claude Code aplica las recomendaciones que pueda (desde la versión 2.1.305).

6. Cómo gastar menos

Los consejos de la documentación oficial que más ahorran:

  1. /clear entre tareas que no tienen relación. Claude Code reenvía toda la conversación en cada mensaje, así que el contexto viejo se paga una y otra vez. /clear no cuesta nada; /compact sí, porque tiene que leer la conversación para resumirla.
  2. Elige bien el modelo. Sonnet resuelve la mayoría de tareas de programación y cuesta menos que Opus. Deja Opus para decisiones de arquitectura o razonamientos de varios pasos. Cámbialo con /model, y en los subagentes sencillos pon model: haiku.
  3. Baja el esfuerzo en tareas simples con /effort (por ejemplo /effort low). Los tokens de razonamiento se cobran como tokens de salida.
  4. CLAUDE.md corto. Se carga entero al empezar cada sesión. La documentación recomienda menos de 200 líneas y pasar las instrucciones de flujos concretos a skills, que solo se cargan cuando se usan.
  5. Desactiva los servidores MCP que no uses con /mcp y prefiere herramientas de línea de comandos como gh cuando existan.
  6. Pide cosas concretas. «Mejora este código» hace que Claude lea medio proyecto; «añade validación a la función login de auth.ts», no.
  7. Usa el modo plan (Shift+Tab) en tareas grandes y para con Esc en cuanto veas que va por mal camino.

Compruébalo

Abre Claude Code en tu proyecto y mira con qué cuenta estás pagando:

claude --version
claude

Dentro de la sesión:

/status
/usage

En /status verás la cuenta con la que entraste. En /usage, con suscripción, verás las barras de uso de las ventanas de 5 horas y semanal; con API, el coste estimado de la sesión.

Para saber si una clave de API está pasando por delante de tu suscripción sin enseñar la clave en pantalla:

[ -n "$ANTHROPIC_API_KEY" ] && echo "Hay una clave de API: Claude Code cobrará por API" || echo "Sin clave de API: se usa tu suscripción"

Por qué funciona

Claude Code siempre consume tokens del modelo. Lo que cambia es quién los paga. Con suscripción, los tokens salen del margen de tu plan, que se renueva cada 5 horas y cada semana. Con API, cada token se factura a precio de lista. Por eso los mismos consejos (contexto pequeño, modelo adecuado) sirven en los dos casos: con suscripción tardas más en llegar al límite y con API pagas menos.

Errores típicos

  • Pagas Pro o Max y aun así te llega una factura de API → tienes definida ANTHROPIC_API_KEY y Claude Code la usa en lugar de la suscripción → quítala de tu ~/.bashrc o ~/.zshrc, abre otra terminal y vuelve a entrar con /login.
  • «You've hit your session limit» a mitad de tarea → se acabó el margen de la ventana de 5 horas, que es común a todos los modelos → espera al reinicio que indica el mensaje, activa créditos de uso con /usage-credits o sube de plan. Cambiar de modelo con /model no lo arregla.
  • Llegas al límite muy rápido → una sesión abierta todo el día reenvía todo su historial en cada mensaje → usa /clear al cambiar de tarea y revisa en /usage qué consume más.
  • El coste de /usage no coincide con lo que pagas → es una estimación local a precio de lista → con suscripción, fíjate en las barras del plan; con API, la factura real está en la página de uso de Claude Console.

Preguntas frecuentes

¿Hay alguna forma oficial de usar Claude Code gratis?

No. El plan Free no incluye Claude Code y la API cobra por token. El programa se instala gratis, pero usarlo requiere una suscripción de pago o saldo en la API.

¿Cuánto cuesta Claude Code en mi país?

Anthropic publica los precios en dólares estadounidenses (USD) y sin impuestos. Según su centro de ayuda, donde está disponible se cobra en tu moneda local, el precio mensual varía por región, y los impuestos se calculan con la dirección de facturación de tu método de pago: en unas regiones van incluidos en el precio que ves y en otras se suman al pagar. El importe exacto para tu país lo verás en la pantalla de pago antes de confirmar. Aquí no damos precios por país porque Anthropic no publica una lista.

¿Pro es suficiente para programar?

Para probar Claude Code y para un uso de unas horas por semana, sí. Si trabajas con él a diario y te topas con el límite de 5 horas, el siguiente paso es Max (5 veces el uso de Pro).

¿Los límites del chat y de Claude Code son distintos?

No. Son los mismos: todo lo que haces en el chat de Claude y en Claude Code cuenta contra el mismo margen.

¿Qué conviene más, suscripción o API?

Si lo usas a menudo, la suscripción, porque el precio es fijo y previsible. Si lo usas poco o en scripts y CI, la API, porque pagas solo lo que consumes. En ese caso pon un límite de gasto en Console.

¿Los precios pueden cambiar?

Sí. La propia página de Anthropic dice que los precios y planes pueden cambiar a su discreción. Por eso esta página lleva fecha de revisión; antes de pagar, comprueba claude.com/pricing.
