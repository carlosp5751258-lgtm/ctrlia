8 workflows de GitHub Actions

Workflows de CI comentados línea por línea en español, con permisos mínimos y caché.

Abrir en GitHub · gratisVer todas las herramientas

El problema

Sin integración continua, un test roto o una dependencia vulnerable llegan a la rama principal sin que nadie lo note, y te enteras cuando ya falla en producción. Montar GitHub Actions desde cero, con permisos y caché bien puestos, quita tiempo. Estos workflows comentados línea por línea en español prueban Node y Python en cada push y pull request, y revisan tus dependencias cada semana.

Qué incluye

  • node-ci.yml: lint y tests en Node 20 y 22 con caché de npm
  • python-ci.yml: ruff y pytest con uv en 3.11–3.13
  • auditoria-dependencias.yml: revisión semanal de vulnerabilidades

Instálala en un minuto

git clone https://github.com/carlosp5751258-lgtm/github-actions-ci-espanol.git
mkdir -p .github/workflows
cp github-actions-ci-espanol/.github/workflows/node-ci.yml .github/workflows/   # o el de tu lenguaje
github-actions-ci-espanolCódigo, README y licencia MIT en GitHub→

Haz commit y push: el workflow corre solo en cada push y pull request. Cada archivo indica qué cambiar.
