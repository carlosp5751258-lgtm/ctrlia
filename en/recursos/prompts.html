Tested prompts for debugging, refactoring, testing and documenting with any AI assistant.

Open on GitHub · freeSee all tools

The problem

You ask AI for help with a bug or a refactor and it gives you a generic answer that doesn't fit your code. The problem is usually the prompt: it lacks context, the language or exactly what you expect. This repository collects 30 tested prompts for debugging, refactoring, testing and documenting, with placeholders to adapt them to your code and a note on when to use each one.

What’s included

  • 30 prompts: 3 from each of the 10 categories
  • Placeholders to adapt them to your code
  • When to use each one

Install it in one minute

git clone https://github.com/carlosp5751258-lgtm/ctrlia-prompts-programadores.git
# open prompts.md and copy the one you need
