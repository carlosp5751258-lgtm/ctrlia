The problem

Claude can't guess how your project's tests are run: it tries random commands, runs the whole suite when you only wanted one test, or touches files nobody should touch. Every session you repeat the same explanations. These CLAUDE.md templates for Go, FastAPI, Express, Laravel and Astro give it the exact commands, how to run a single test and a “Don't do” section listing the dangerous actions.

What’s included

  • 5 templates: Go, FastAPI, Express, Laravel and Astro
  • How to run a single test in each stack
  • A “Don't do” section with the dangerous actions

Install it in one minute

git clone https://github.com/carlosp5751258-lgtm/ctrlia-plantillas-claude-md.git
cp ctrlia-plantillas-claude-md/plantillas/go.md ./CLAUDE.md   # pick the one for your stack
ctrlia-plantillas-claude-mdCode, README and MIT license on GitHub→

Adjust the commands to your project and restart Claude Code: it reads the file at the start of every session.
