Claude Code Guide: Zero to Expert

The first chapters of the “Claude Code: Zero to Expert” guide: installation, how to ask for tasks and CLAUDE.md.

Open on GitHub · freeSee all tools

The problem

You install Claude Code, ask it for something, and sometimes it gets it right and sometimes it does weird things: it touches files it shouldn't or doesn't understand your project. It's almost never the model; it's how tasks are requested and what it knows about your repository. The free first chapters of this guide cover installation, how to ask for tasks so they come out right, and how to use CLAUDE.md as your project's memory.

What’s included

  • Chapter 0: before you start
  • Chapter 1: installation and first steps
  • Chapter 2: how to ask for tasks
  • Chapter 3: CLAUDE.md, your project's memory
