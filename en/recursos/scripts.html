The problem

Cleaning node_modules, freeing a busy port, updating your repos or deleting old branches: small tasks you repeat every week by copying commands from the internet, some of them dangerous. These bash scripts do it for you safely: a preview before deleting, dry-run by default for branches, --help in every script and confirmation before any destructive action.

What’s included

  • Clean node_modules and caches (with a preview)
  • See and free busy ports
  • Update all your repos with pull --ff-only
  • Generate .gitignore offline
  • Delete merged branches (dry-run by default)

Install it in one minute

git clone https://github.com/carlosp5751258-lgtm/ctrlia-scripts-bash.git
cd ctrlia-scripts-bash && chmod +x *.sh
./02-limpiar-caches.sh --help
